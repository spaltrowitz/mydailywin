## What Was Tasked

Fix admin portal tab functionality and layout issues:
- Tabs not responding to clicks
- Settings tab wrapping to second row on desktop
- Event delegation handler not in proper scope

## What Was Done

### 1. Event Delegation Handler Scope Fix
- **File:** js/admin.js (lines 1422-1450)
- **Issue:** Handler was at top-level scope but called functions defined in auth callback closure
- **Fix:** Moved event delegation handler inside `auth.onAuthStateChanged()` callback
- **Outcome:** All click handlers now have access to `showTab()`, `openAddTaskModal()`, etc.

### 2. Tab Layout: Horizontal Scroll
- **File:** css/admin.css (tabs section)
- **Issue:** 7 tabs wrapped to second row on narrower desktop screens
- **Fix:** Changed `flex-wrap: wrap` → `flex-wrap: nowrap` + `overflow-x: auto`
- **Styling:** Reduced padding (12px→10px horizontal), added `flex-shrink: 0`, `white-space: nowrap`, `scrollbar-width: thin`
- **Outcome:** Consistent single-row horizontal scroll (matches mobile pattern)

### 3. Tab Matching Fallback
- **File:** js/admin.js (`showTab()` function)
- **Issue:** Fallback check looked for non-existent `onclick` attribute
- **Fix:** Changed to `t.getAttribute('data-arg') === tabId`
- **Outcome:** Tab activation works correctly with CSP-compliant data-* attributes

## Decisions Made

1. **Scope containment:** Event handlers must be in same closure as functions they call
2. **Horizontal scroll > wrapping tabs:** Better UX for consistency and predictability
3. **CSP compliance:** Use data-* attributes exclusively, remove reliance on onclick
